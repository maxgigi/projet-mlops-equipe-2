□ Cluster Kubernetes : nœuds Ready, DNS fonctionnel, application témoin joignable.
□ Stockage persistant testé : le pod redémarre, les données restent.
□ MLflow accessible (base PostgreSQL ou SQLite, artefacts dans MinIO ou sur un volume) ; runs visibles dans l'interface.

□ KServe installé (le mode RawDeployment suffit) ; InferenceService à l'état Ready.
□ Appel d'inférence JSON : la prédiction obtenue est la même que celle calculée en local.
□ Test fonctionnel automatisé et documenté.
□ Dépôt Git avec un README qui permet de refaire le MVP (une installation manuelle documentée est acceptée).
□ Schéma d'architecture et au moins 4 ADR.
□ Chaque étudiant sait raconter le chemin d'une requête d'inférence, du client jusqu'au modèle et retour.
