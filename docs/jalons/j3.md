Checklist au jalon 3 : Kubernetes opérationnel

- □ Installation scriptée (kubeadm ou k3s) ;
- □ CNI en place ;
- □ DNS (CoreDNS) en place ;
- □ Ingress controller en place ;
- □ metrics-server en place ;
- □ StorageClass en place ;
- □ Application témoin : Deployment, Service, Ingress, ConfigMap, Secret, PVC ;
- □ Requests/limits définis sur l'application témoin ;
- □ HPA (HorizontalPodAutoscaler) ;
- □ Panne n°1 provoquée ou rencontrée, résolue et documentée : ex1 ;
- □ Panne n°2 provoquée ou rencontrée, résolue et documentée : ex2 ;
- □ Panne n°3 provoquée ou rencontrée, résolue et documentée : ex3 ;
- □ Registre d'images local ;
- □ Schéma du cluster.
